## 📌 Project Overview

QuizMind is a fully interactive multiple-choice quiz application that tests knowledge on Computer Science and Web Development fundamentals. It solves the need for an engaging, self-paced learning tool that provides instant feedback and meaningful performance insights.

Built as part of the **Syntecxhub Front-End Development Internship (Week 3)**, this project demonstrates advanced JavaScript skills including dynamic DOM rendering, conditional logic, score tracking, and state management — all without any external libraries.

---

## ✨ Features

- 🎯 **Welcome Screen** — Clean intro screen with quiz info before starting
- 📋 **6 Multiple-Choice Questions** — Computer Science & Web fundamentals
- 1️⃣ **One Question at a Time** — Focused, distraction-free quiz flow
- ⚡ **Instant Answer Feedback** — Green ✅ for correct, Red ❌ for wrong answers
- 💡 **Correct Answer Reveal** — Shows the right answer if user picks wrong
- 📊 **Live Score Counter** — Real-time score updates as you progress
- 📈 **Progress Bar** — Visual indicator of quiz completion percentage
- 🏆 **Dynamic Result Screen** — Personalized message based on performance level
- 📉 **Detailed Stats** — Final score, correct count, wrong count, and accuracy %
- 🔄 **Restart Option** — Play again without refreshing the page
- 📱 **Fully Responsive** — Works seamlessly on mobile and desktop

## 🚀 Installation & Setup

No installation required! This is a static HTML file.

```bash
# 1. Clone the repository
git clone https://github.com/nehamirsa12/Syntecxhub_Quiz_App.git

# 2. Navigate into the project folder
cd Syntecxhub_Quiz_App

# 3. Open in browser
# Simply double-click quiz_app.html
# OR open with Live Server in VS Code
```

---

## 📖 Usage

```
1. Open quiz_app.html in any browser
2. Click "Start Quiz →" on the welcome screen
3. Read each question carefully
4. Click one of the 4 answer options (A / B / C / D)
5. Instant feedback shows if you were correct or wrong
6. Click "Next Question →" to proceed
7. On the last question, click "Submit Quiz"
8. View your final score, accuracy, and personalized message
9. Click "🔄 Try Again" to restart the quiz
```

## 🧠 Challenges & Learnings

| Challenge | Learning |
|---|---|
| Managing quiz state across multiple screens | Learned clean state management with JavaScript variables |
| Rendering options dynamically from a data array | Mastered `forEach` + `createElement` for dynamic DOM generation |
| Disabling options after selection to prevent re-answering | Used `disabled` attribute toggling via JavaScript |
| Calculating and displaying dynamic result messages | Implemented conditional logic with percentage thresholds |
| Smooth screen transitions without a framework | Used CSS `@keyframes` fadeIn with class toggling |
